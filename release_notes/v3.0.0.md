## Package boundary

The future v3.0.0 fixed ZIP is a Public DRC source package. It will not bundle
AI Character Framework, private operator evidence, credentials/tokens, local
data, raw audio/logs, databases, generated build outputs, or nested release
artifacts. Configured manual VTS motion requires separately obtaining and placing
the fixed released Framework v5.5.0.

- App Store / Google Play readiness or signed APK, AAB, or MSIX distribution.
