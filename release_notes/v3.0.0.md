## Release highlights

- Guarded, bounded microphone capture and app-visible configured real-STT path.
- Bounded SSE text streaming with cooperative cancellation.
- DRC-owned bounded voice queue/output control and local soft barge-in.
- Realtime character presentation and provider-neutral motion mapping.
- Guarded manual VTube Studio motion through separately supplied fixed released
  AI Character Framework v5.5.0.
- Accepted configured PC Windows and Android realtime operator paths.
- Safe defaults, explicit opt-in controls, and visible execution state.

## Package boundary

The fixed v3.0.0 ZIP is a Public DRC source package. It will not bundle
AI Character Framework, private operator evidence, credentials/tokens, local
data, raw audio/logs, databases, generated build outputs, or nested release
artifacts. Configured manual VTS motion requires separately obtaining and placing
the fixed released Framework v5.5.0.

## Conservative non-claims

This release does not claim:

- Provider-level hard cancel or Backend HTTP hard cancel.
- A Framework unified realtime runtime or real TTS queue flush.
- Always-on/background microphone or automatic next-turn capture.
- Automatic voice-to-motion synchronization or automatic emotion inference.
- Acceptance on all Android devices or iOS realtime acceptance.
- Production multi-user hosting or production security readiness.
- App Store / Google Play readiness or signed APK, AAB, or MSIX distribution.
- Bundled AI Character Framework or release-ZIP-only immediate configured VTS
  execution.
