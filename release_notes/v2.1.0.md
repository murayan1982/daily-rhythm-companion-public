## Highlights

- Google Health is the configured real health-data path, with accepted operator evidence that Fitbit Versa 2-origin sleep reached the normalized sleep summary and PC/smartphone Web UI.
- Post-advice chat has bounded session/turn lifecycle outcomes, structured recovery states, and restart behavior.
- Generated voice output can be played, stopped, replayed, expired, and regenerated inside the Flutter app.
- Character mood/advice/fallback and idle/loading/speaking states use a deterministic app-owned presentation model and static display card.
- Mock-safe defaults and explicit real-provider opt-in boundaries remain intact.
- Final candidate evidence is governed by public-safe validators and ignored private evidence; no raw screenshots, audio, health values, paths, or operator evidence enter source or release artifacts.
