# Daily Rhythm Companion v2.1.0

Status: RELEASE CANDIDATE / NOT_RELEASED

Daily Rhythm Companion v2.1.0 expands the public demo from the v2.0.1 maintenance baseline with wearable-data verification, bounded post-advice chat, in-app voice playback, and deterministic character presentation. These notes describe the candidate source; no v2.1.0 tag, fixed ZIP, or GitHub Release exists yet.

## Highlights

- Google Health is the configured real health-data path, with accepted operator evidence that Fitbit Versa 2-origin sleep reached the normalized sleep summary and PC/smartphone Web UI.
- Post-advice chat has bounded session/turn lifecycle outcomes, structured recovery states, and restart behavior.
- Generated voice output can be played, stopped, replayed, expired, and regenerated inside the Flutter app.
- Character mood/advice/fallback and idle/loading/speaking states use a deterministic app-owned presentation model and static display card.
- Mock-safe defaults and explicit real-provider opt-in boundaries remain intact.

## Compatibility and safety

- Backend semantic version: `2.1.0`
- Flutter package version: `2.1.0+3`
- Existing v2.0.0 and v2.0.1 tags, Releases, fixed ZIPs, and historical records remain immutable.
- Credentials, tokens, exact sleep values, raw provider payloads, generated audio, screenshots, private paths, LAN IPs, and operator evidence are excluded from source and release artifacts.
